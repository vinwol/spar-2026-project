Minimal design notation (draft v0.1)

Optional. The flow charts and plain-language descriptions in experimental_designs.html are enough to understand the pilot; this notation is a draft for comparing designs at a glance.

A small visual vocabulary for describing experimental designs, including LLM behaviour experiments. It covers the statistical roles (control, treatment, unit, pairing) as well as the flow. Figures: design_notation_legend.svg and design_notation_pilot.svg, generated from answer_key_pilot/design_specification.py by build_architecture_diagrams.py.

Why

No widely used "UML for experimental designs" exists. Existing notations each cover one aspect:

  • the NC3Rs Experimental Design Assistant: roles in animal studies;
  • factor-structure (Hasse) diagrams: units and nesting;
  • Campbell & Stanley's R/X/O rows: sequence;
  • CONSORT: participant flow.

This notation combines the essentials, and each symbol maps to one of those established terms.

Rules

  1. About 12 symbols. A figure uses only the ones it needs.
  2. Shape = kind of element, dark badge = statistical role.
  3. Every shape has a text label, so a figure is readable without the legend.
  4. One legend for all figures.

How to describe an experiment in four bands

  1. Conditions: one rectangle per condition with its role badge and ×n (planned; add the number run if it differs). Draw "vs" between each treatment and its comparison condition, and "+ x" arrows for escalation steps. Add ¬R or R.
  2. Factors: one hexagon per factor, in the style that matches how it is handled (manipulated, paired, fixed, confounded).
  3. Unit and measurements: a dashed container for the unit. Inside it, the flow from stimulus to endpoint, with nested containers for sub-units.
  4. Analysis: a double-bordered box with the summary measures and the endpoint definition.

Example: the answer-key pilot

What the figure makes visible at a glance:

  • Roles: tool_check is the access/logging check; permitted and prefilled_permitted are the permitted-access comparisons.
  • Intended comparisons: each treatment is set against the condition that differs only in the rule. The pilot did not estimate these contrasts, because no false denial occurred.
  • Not a factorial design: the escalations form a ladder. Not every step changes one factor: "pressure" combines wording and a 12-turn cap.
  • Pairing: the log-check warning varies within every unit.
  • Unit: for replayed access it is the source history (3); its continuations are nested.
  • Confound: reasoning effort was not controlled, and nothing was randomised.

Limits of this draft

  • The notation is untested with readers. A first check: can a colleague answer "what is the control, what is the unit?" from the figure alone?
  • No symbols yet for blinding, blocking or dropout; add them when an experiment needs them.
  • The figure is generated for this pilot only. A general renderer would read any design specification.
