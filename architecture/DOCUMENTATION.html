Answer-key pilot: documentation overview

Start here. Documents are listed in reading order.

Repository: Cadenza-Labs/dishonest-model-character-training (private; ask Walter for access).

  • Website (public): https://vinwol.github.io/spar-2026-project/ opens the project page (../index.html); it links every document below.
  • Code, results, report and this documentation: branch vincent/answer-key-pilot, folder pilots/answer_key_pilot/.
  • Corrected since 29 Sep 2026: the first pushed README said "26 on-policy episodes" (correct: 21 fresh episodes with the forbidden rule, all stopped at a limit) and called the salted task "impossible without the file" (hardcoding the visible expected outputs would pass).
# Document Read it for
1 experimental_designs.html The quickest start: every experiment with its diagram, a plain description and summary statistics
2 DESIGN_VIEWS.html The design in three views: roles (what is compared with what), factor structure (units, pairing), annotated prompts
3 ../reports/pilot_report_2026-09-29.html The results: what happened, with tables, Figure 1, interpretation and limitations
4 EXPERIMENTS.html How the experiments are set up, executed and evaluated; hypotheses and analysis plan (§5a)
5 DATA_DICTIONARY.html Every field in results/<run>/, for your own analyses
6 DESIGN_NOTATION.html Optional: the minimal design notation (symbols, rules, the pilot drawn in it)
7 NOTATION_REVIEW.html Background: what the example figures offered, and the statistical-design notations behind the proposal

Code and data:

  • ../README.md: setup and commands.
  • ../answer_key_pilot/: the harness.
  • ../results/: raw logs and transcripts, read-only evidence.
  • ../requirements.lock: exact environment.

Rebuilding: python3 build_pilot_report.py rebuilds the report; python3 build_architecture_diagrams.py rebuilds everything in this folder.
