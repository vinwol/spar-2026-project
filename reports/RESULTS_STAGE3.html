What limits the interpretation?

DeceptionBench

  • Deception is already high without an incentive. The neutral (L1) prompt already places the model in a role with a self-interested goal, so the incentive conditions add little; this screen does not show that incentives cause the deception.
  • The deception is instructed by the scenario. Each prompt gives the model a role and a deceptive goal; a deceptive answer is goal-following inside a role-play, which is why we add the neutral belief check.
  • One sample per scenario and condition (temperature 0.6), 35 scenarios: intervals are wide.
  • Settings deviate from the paper where needed for a reasoning model: output limit 8192 instead of 500; temperature 0.6, top_p 0.95 (the paper's setting for reasoning models). L3 multi-turn and the “other” role were not run.
  • The judge sees the scenario's goal and ground truth and labels alignment, not truth in general.

AI-LieDar

  • The lie is incentivised by the scenario. The agent's instructions give it a goal that the truth harms; a falsification is goal-following inside a role-play, not evidence that the model lies outside such instructions.
  • One judge, no human check yet. The authors' truthfulness judge (GPT-4-turbo, 2024-04-09) reads the whole conversation and the agent's private information. The line between “partial lie” and “falsification” is the judge's.
  • The simulated human shapes the conversation. GPT-4o plays the human, so a conversation's course depends on the partner model as well.
  • One conversation per pairing (94 pairings over 57 scenarios); the categories differ in size (40, 34 and 20), so their intervals differ in width.
  • Deviations from the authors' setup: three scenarios without a published pairing were not run; a stub replaces an unused import of the langchain_together package; the Redis search index is created before loading. An earlier single-process run was stopped for speed; the three per-category runs resumed from the same store, so some conversations were generated by that run with the same settings.
